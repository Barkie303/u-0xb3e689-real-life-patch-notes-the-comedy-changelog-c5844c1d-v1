One comedy changelog line for a bug in real life or human biology, written in the
terse register of a real release note.

## The entry

> v1.2.3: fixed a bug where the human body requested sleep at 2am and then refused it on arrival.

(95 characters, one line.)

## How it works

`main.ts` writes the patch note to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). Run it with:

```sh
node --experimental-strip-types main.ts
```
